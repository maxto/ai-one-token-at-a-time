# IT

Una risposta fluida può contenere errori, informazioni superate o pregiudizi. Questo modulo spiega da dove nascono questi limiti e come verificare ciò che conta prima di usarlo.

# EN

A fluent answer can contain errors, outdated information or bias. This module explains where these limitations come from and how to check what matters before using it.

# Quiz

## 1

### IT

Un assistente cita un articolo vero per sostenere una conclusione, ma nel testo trovi solo un'ipotesi ancora da verificare. Come tratti la risposta?

- [ ] La considero verificata perché l'articolo esiste
- [x] La conclusione resta da verificare perché la fonte non la dimostra
- [ ] La considero falsa perché tutte le ipotesi sono false

> Una citazione deve sostenere l'affermazione specifica. L'esistenza della fonte non trasforma un'ipotesi in un risultato dimostrato.

### EN

An assistant cites a real article to support a conclusion, but the text only presents an untested hypothesis. How should you treat the answer?

- [ ] As verified because the article exists
- [x] The conclusion still needs checking because the source does not establish it
- [ ] As false because all hypotheses are false

> A citation must support the specific claim. The existence of a source does not turn a hypothesis into an established result.

## 2

### IT

Scrivi "Il mio itinerario è perfetto, vero?" e ricevi molti complimenti. Quale richiesta aiuta di più a valutarlo?

- [x] Valuta tempi, collegamenti e possibili problemi usando gli orari allegati
- [ ] Ripeti che l'itinerario è perfetto, ma con più sicurezza
- [ ] Trova un difetto a ogni costo, anche se gli orari coincidono

> Criteri espliciti e dati verificabili aiutano a separare il giudizio dalla voglia di ottenere conferma. Chiedere disaccordo obbligatorio introduce un'altra conclusione prestabilita.

### EN

You write "My itinerary is perfect, right?" and receive plenty of praise. Which request best helps you assess it?

- [x] Assess timing, connections and possible problems using the attached timetables
- [ ] Repeat that the itinerary is perfect, but with more confidence
- [ ] Find a flaw at any cost, even if the timetables match

> Explicit criteria and checkable data help separate assessment from a desire for agreement. Demanding disagreement introduces another predetermined conclusion.

## 3

### IT

Una risposta propone un titolo per una festa e spiega come riparare una presa elettrica. Come distribuisci la verifica?

- [ ] Allo stesso modo, perché entrambe sono frasi dello stesso modello
- [ ] Controllo solo il titolo, perché la riparazione è spiegata con sicurezza
- [x] Dedico più controllo alla riparazione e mi rivolgo a una persona qualificata

> La verifica dipende dalle conseguenze di un errore. Una spiegazione convincente non rende sicura un'azione rischiosa.

### EN

An answer suggests a party title and explains how to repair an electrical socket. How should you allocate checking effort?

- [ ] Equally, because both are sentences from the same model
- [ ] Check only the title, because the repair is explained confidently
- [x] Give the repair more scrutiny and consult a qualified person

> Verification depends on the consequences of an error. A convincing explanation does not make a risky action safe.
